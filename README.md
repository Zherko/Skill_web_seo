# Skill_web_seo

Skill de OpenCode para auditar, planificar e implementar mejoras SEO: SEO técnico, on-page, structured data, Core Web Vitals, estrategia de contenidos y citabilidad IA (llms.txt, AI crawlers, extracción LLM).

Activa con `/skill_web_seo`.

## Instalación

```bash
# global
git clone https://github.com/Zherko/Skill_web_seo ~/.config/opencode/skills/skill_web_seo

# o por proyecto
git clone https://github.com/Zherko/Skill_web_seo .opencode/skills/skill_web_seo
```

Luego usa `/skill_web_seo` en OpenCode, o dispara con lenguaje natural: "audita SEO", "mejora el SEO", etc.

## Contenido

- `SKILL.md` — skill completa (737 líneas): checklists técnicos, on-page, internal linking, image SEO, AI SEO & citabilidad, Static HTML Blog Pattern con template de artículo, RSS, sitemap, tracking opcional.
